# Dream Home Builders

Custom luxury home builder website for Edison, New Jersey — Dream Home Builder branding, project galleries, services, testimonials, and quote forms.

## Run

```bash
npm run dev
```

Open: **http://localhost:5180/**

- `/` Home  
- `/apartments` Projects listing  
- `/contact` Contact / quote  
- `/success` Form thank-you page  

Live brand site reference: [dreamhomebuildersnj.com](https://dreamhomebuildersnj.com)
